# Naval Battle (Pygame)

A classic arcade-style naval shooting game built with Python and Pygame.

## Features
- Smooth left and right ship controls
- Cannon firing with synthesized sound effects
- Particle explosion animations on ship hits
- Live score tracking

## How to Run
1. Install Pygame:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python naval.py
   ```

## Controls
- **Left / Right Arrows** (or **A / D**): Move ship
- **Spacebar**: Fire cannon
